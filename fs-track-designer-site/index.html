A Importar o polígono do Google Earth

Escolher .kml / .kmz
Como exportar o polígono do Google Earth (web)
  1. Garante que o polígono está guardado (botão Concluído).
  2. No painel Conteúdo do mapa, clica nos ⋮ ao lado do título (ou nos ⋮ do projeto na lista de Projetos).
  3. Escolhe Exportar como ficheiro KML. Se só aparecer KMZ, também serve.
  4. Carrega aqui o ficheiro. Se tiveres vários polígonos (ex.: reta de cima + ligação + pista), entram todos como área utilizável.

Dica: desenha o polígono pelo limite do asfalto limpo (sem bermas/gravilha). A margem de segurança aplica-se depois.

C Desenhar a área à mão

Por cima da imagem de fundo: clica nos cantos do asfalto. Enter fecha, Backspace apaga o último, Esc cancela.

Clica num polígono (aqui ou no mapa) para o selecionar. Em Editar: arrasta os vértices, arrasta os ◇ do meio das arestas para criar um vértice novo, Alt+clique ou clique-direito num vértice para o apagar.

Referência (origem local)

x = Este, y = Norte, em metros a partir deste ponto. É definido automaticamente ao importar o KML.

Partida

Rumo: 0° = Norte, 90° = Este. No mapa arrasta o ponto laranja (mover) e o triângulo (rodar, Shift = livre).

Importar no Google Earth (web)
  1. Abre ou cria um projeto → no painel Conteúdo do mapa carrega em +.
  2. Importar ficheiro → Do computador → escolhe o .kml.
  3. O KML mantém as cores (azul/amarelo/laranja); o GeoJSON pode aparecer com cores por defeito.

Cones para marcar no terreno (CSV)

Coordenadas lat/lon e x/y locais (m) de cada cone, em ordem de volta. Para implantar com fita métrica a partir de 2 pontos de referência, ou com GNSS RTK se tiverem.
